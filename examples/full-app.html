Full App Example (Xpell 2 Alpha)

Reference structure for a client + server app using @xpell/ui, @xpell/node, and Wormholes.

What this example demonstrates

  • @xpell/ui app shell with 2-3 screens (dashboard, list, edit).
  • @xpell/node module with 2-3 ops (list/create/update).
  • Wormholes call path from client to server operation.
  • Simple real-time update (server emit + client refresh): planned.
