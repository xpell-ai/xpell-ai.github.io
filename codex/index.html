Codex Skills (Xpell 2 Alpha)

Codex skill workflow for runtime-first app generation. Contracts are alpha and expected to evolve.

Get Codex Skills

What the Xpell Codex skill does

  • Generate app skeletons across client and server layers.
  • Generate views as structured data compatible with nano-command contracts.
  • Generate XModule operation stubs for @xpell/node (xnode).

Installation (Preview)

Release: github.com/xpell-ai/xpell-codex-skills/releases/latest

  • Prepare a workspace with your Xpell app files.
  • Download the latest release package from the link above.
  • Run generation prompts from the project root so outputs stay local and auditable.

Generate a full app example prompt

Generate a full Xpell 2 Alpha app with @xpell/ui screens, @xpell/node module ops (list/create/update), and Wormholes calls between client and server.

Notes

  • This is Alpha; contracts and templates evolve.
  • Prefer file-based views with explicit structured data.
  • Vibe Coding is supported as a concept; the VIBE UX layer comes later.
